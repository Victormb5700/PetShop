# 🐾 PetShop

Sistema web para gerenciamento de agendamentos de um Pet Shop.

O projeto permite cadastrar, visualizar, editar e excluir agendamentos de pets, além de pesquisar e filtrar os atendimentos.

## 📌 Funcionalidades

* Cadastrar agendamentos
* Visualizar agendamentos
* Editar agendamentos
* Excluir agendamentos
* Pesquisar agendamentos
* Filtrar por animal
* Filtrar por data
* Escolher data e horário
* Adicionar observações sobre o atendimento
* Cadastro de cães e gatos

## 🛠️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* Node.js
* Express
* MySQL
* Flatpickr

## 💾 Banco de dados

O projeto utiliza o **MySQL** para armazenar os dados dos agendamentos.

O arquivo para criar o banco está na pasta:

```text
sql/criar_banco_petshop.sql
```

## 🚀 Como instalar

Primeiro, clone o projeto:

```bash
git clone https://github.com/Victormb5700/PetShop.git
```

Entre na pasta:

```bash
cd PetShop
```

Depois instale as dependências:

```bash
npm install
```

## ▶️ Como iniciar o projeto

Execute:

```bash
npm start
```

Depois abra o navegador e acesse:

```text
http://localhost:3000
```

## 📅 Como usar

Na tela principal é possível criar um novo agendamento.

Para isso, informe os dados do pet, escolha a data e o horário e adicione uma observação caso seja necessário.

Depois de cadastrar, o agendamento aparecerá na lista.

Também é possível:

* Editar um agendamento;
* Excluir um agendamento;
* Pesquisar um atendimento;
* Filtrar os agendamentos.

## 🔄 CRUD

O projeto possui as operações básicas de CRUD:

* **Create:** criar agendamento
* **Read:** visualizar agendamento
* **Update:** editar agendamento
* **Delete:** excluir agendamento
